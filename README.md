# 🌾 Project Kisan

**Project Kisan** is an AI-powered voice-first assistant built to support small-scale farmers in India with expert help on demand.

### 🧠 The Problem

Rohan, a young farmer in rural Karnataka, notices yellow spots on his tomato plants. Unsure whether it’s a pest, fungus, or fertilizer issue — and with the nearest agricultural office miles away — he risks losing his crop before getting help. On top of that, mandi prices fluctuate daily, and understanding government schemes is complex and often not in his native language.

### 🎯 The Solution

**Project Kisan** provides farmers like Rohan with a personal digital ally that:

- Diagnoses crop diseases instantly via image upload using Gemini Pro Vision (Vertex AI)
- Allows voice queries in local languages (like Kannada) and responds via text and speech
- Delivers real-time mandi price updates and trend analysis
- Explains relevant government schemes with eligibility and direct links
- Works as a web-based, mobile-friendly assistant using only HTML, CSS, JavaScript, and Firebase

### 🔗 Key Technologies

- Vertex AI Gemini (multimodal API)
- Web Speech API (STT + TTS)
- Firebase Hosting + Storage
- Fully responsive vanilla web interface
